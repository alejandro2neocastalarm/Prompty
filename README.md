# Prompty

Va a ser una app minimalista, que genera prompts, le subes lo que quieres que haga la IA, también puedes subir imágenes, archivos, y otra IA te da el prompt adecuado, que haya un selector con un montón de modelos para hacer un prompt adecuado al modelo, que haya un boton para poner el fondo oscuro o claro y otro para cambiar de idioma. que sea minimalista y una única pantalla. - 🎨 Diseño como la imagen (oscuro/claro). 

- 📝 Un único cuadro de texto para explicar lo que quieres. 

- 📷 Botón para subir imágenes. 

- 📄 Botón para subir archivos (PDF, Word, etc.). 

- 🤖 Selector de modelos (GPT-5, GPT-4.1, Claude, Gemini, Grok, etc.). 

- ✨ Botón **Generar Prompt**. 

- 🌍 Selector de idioma. 

- 🌙 Botón de modo oscuro/claro. 

- 📋 Botón para copiar el prompt generado. 

- 📱 Totalmente responsive para móvil y PC.  - Drag & Drop de archivos. 

- Vista previa de imágenes. 

- Cambio de idioma instantáneo. 

- Historial opcional. 

- Animaciones suaves. 

- Efecto cristal (Glassmorphism muy sutil). 

- Degradados morado-azules como el logo. Hazme el proyecto completo y hazlo seguro q es para subir a github. Yo lo que quiero es que haya un selector de lenguaje, de modelo de IA. Y para que haga el prompt adecuado al modelo de IA que hayas seleccionado. Si, por ejemplo, quieres hacer un prompt para OpenAI o GPT.5 o lo que sea, pues que te haga un prompt adecuado a ese modelo de IA.  Y luego quiero que prompty le haga preguntas para mejorar el prompt. Por ejemplo, ¿y qué? y, por ejemplo, ¿y de qué color quieres el no sé qué? o tal, ¿sabes? Que le haga preguntas para generar el prompt ideal. Haz la web igual que la foto
